# NÜ-LINE Digital Book Website — Version 2

Version 2 includes the complete supplied Edition I sequence with the newly created Page 15.

## Included
- Cinematic opening cover
- 22 digital-book screens including the cover
- New Page 15: **Residence 9 in Practice**
- Page-turn transitions
- Swipe navigation on iPhone and iPad
- Arrow and keyboard navigation on desktop
- Contents drawer with thumbnails
- Deep links to individual pages
- Project enquiry email link
- Progressive Web App support
- Vercel configuration
- Optimised page images

## Upload completely
1. Create or open the public website GitHub repository.
2. Extract this ZIP.
3. Upload **everything inside the extracted folder** to the repository root.
4. Replace all matching files.
5. Commit directly to `main`.
6. Wait for Vercel to show **Ready**.
7. Refresh the live website fully on iPhone.

This public website repository should remain separate from `nu-line-crm`.
